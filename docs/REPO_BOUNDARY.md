# YD Repository Boundary

## Purpose

This repository contains product code and repository-facing project documents for YD.

## Keep in this repository

- source code
- build and runtime definitions
- repository-facing architecture, PRD, and phase documents
- documents that should be versioned and shared through GitHub

## Keep out of this repository

The following belong in `projects/YD/work`, not here:

- team coordination files
- personal or role-based worklists
- temporary run artifacts
- local test input files
- draft notes that are not ready for repository sharing
- local investigation outputs

## Rule of thumb

If a file exists mainly to help local execution, internal coordination, or temporary project operations, it belongs in `../work` rather than this repository.
