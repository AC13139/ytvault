# YtVault Project Conventions

## Status
This project inherits team-wide standards and is not allowed to drift without explicit justification.

## Inheritance order
1. Team charter
2. Team governance framework
3. Team standards under `workspace/docs/standards/`
4. Project-specific conventions in this folder
5. Task-level instructions

## Current rule
Until project-specific exceptions are documented, YtVault defaults to team-wide principles for product, design, engineering, documentation, and review.

## Change control
Any YtVault-specific exception must document:
- why the default team rule is insufficient
- scope of exception
- whether it is temporary or permanent
- who approved it
